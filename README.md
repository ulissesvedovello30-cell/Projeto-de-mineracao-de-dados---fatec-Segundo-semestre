# Projeto-de-mineracao-de-dados---fatec-Segundo-semestre
Projeto de Mineração de Dados com 72.528 acidentes em rodovias federais brasileiras (PRF, 2025). Usa K-Means para identificar perfis de acidentes e Apriori para descobrir combinações de fatores ligadas a acidentes fatais. Python, pandas, scikit-learn e mlxtend.
